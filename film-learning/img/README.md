## Replacements / 替换

Replace a JPG using its existing descriptive basename, update its corresponding `-diagram.svg`, then update the credits and descriptions in **both** manifest files. The paired SVG viewBox is `0 0 360 203`; the main accent is `#409aba`. A new image needs an appropriate original drawing and accurate attribution; do not retain a diagram that describes the old frame. The current CSS uses a 16:9 slot with `object-fit: contain` to avoid distortion/cropping.

替换 JPG 时请同时修改同名 `-diagram.svg`，并更新两份清单的中英说明与来源。SVG 画布为 `0 0 360 203`，强调色为 `#409aba`。新图应有对应线稿，不可让旧线稿继续解释不同画面。

`intention-overview-01.jpg` through `intention-overview-05.jpg` preserve the five smaller images embedded on **Composition & Intention p. 2**. The site instead displays the corresponding higher-quality p. 3–7 frames to avoid duplicate teaching rows. No original PDF or embedded PDF font is included in the site.
